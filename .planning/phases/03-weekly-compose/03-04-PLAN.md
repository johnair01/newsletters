**Recorded decisions this plan implements (03-VALIDATION Wave 0 — implement, do not reopen):**
- **The deck is TEXT-ONLY this phase.** Phase 2's writer has no `add_picture` path at all and
  `bind_slots` refuses any shape without a text frame; no success criterion budgets image
  placement. An `AssetBlock` reaches the HTML surface and can contribute its caption to a text
  slot; the image itself does not reach the deck. This is recorded in `docs/weekly-spec.md` in this
  plan and raised in the PR body as an honest round-two item — never left implicit.
- **`.csv` is a wording clarification, not scope.** The live ADAPT-03 adapter is `.xlsx`-only; a CSV
  path would require a new adapter module, which WKLY-04 forbids. Values enter as `.xlsx` exports.
  Record the clarification; do not build a CSV reader.
- **Empty sections both disclose and stay renderable.** Chosen mechanism, needing no writer change
  and inventing no prose: `weekly_slots` always emits all four slot keys, and an empty section's
  single line **is** that section's own `missing[]` disclosure string. `weekly_slots` raises if the
  line it is about to emit is not present in `surface.missing`, so the text on the slide is
  provably the disclosure and can never drift into invented content. This supersedes 03-RESEARCH's
  "omit empty slots" rule for slots the template declares — record the supersession and the reason.

**Slot contract (from `pptx_writer.bind_slots`, which fails loud in both directions):** keys must be
`NL_`-prefixed; a key the template does not contain is refused; an `NL_` shape left unfilled is
refused. The committed synthetic template declares exactly four: `NL_WEEK_TITLE`, `NL_MODULE`,
`NL_HIGHLIGHTS`, `NL_LOWLIGHTS` (plus an unprefixed `Footer` the renderer must leave alone). Values
must be explicit `list[str]` — a bare `str` is a `Sequence[str]` of characters (Pitfall 6).

**Determinism assertions:** raw bytes only for an **in-process** double render; `part_digest` for any
cross-environment claim (DEFLATE output is zlib-implementation-dependent). **No test may compare a
rendered deck to the template** — reopening and re-saving the template already yields a different
digest, a python-pptx load-path property, not a regression (Phase 2-03 decision).

**Environment:** `openpyxl` is not installed and no CI job installs `[excel]`; all 64 baseline skips
are excel skips. Task 2 installs it locally and Task 3 installs it in CI. An `importorskip` alone is
not proof — that is verbatim the W21 friction this repo already paid for once.
